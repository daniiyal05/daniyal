# React Vite Project

A small React project built with Vite and TypeScript.

## Project structure

- `index.html` — app entry HTML
- `src/main.tsx` — app bootstrap
- `src/App.tsx` — main React component
- `src/index.css` — global styles
- `src/components/ShaderBackground.tsx` — example component
- `package.json` — project metadata and scripts
- `tsconfig.json` — TypeScript configuration
- `vite.config.ts` — Vite configuration

## Requirements

- Node.js (LTS recommended)
- npm

## Setup

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Open the displayed local URL in your browser (usually `http://localhost:3000`).

## Build for production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Additional scripts

- `npm run lint` — Type-check the project with TypeScript
- `npm run clean` — remove `dist` and `server.js`

## Notes

This project uses Vite, React 19, Tailwind CSS, and TypeScript.
